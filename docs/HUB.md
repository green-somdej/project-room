# 🤝 ศูนย์ร่วมโครงการ (Eco Hub) — แนวคิดและการออกแบบ

หน้าเว็บ: `docs/join.html` (ลิงก์ "🤝 ร่วมโครงการ" ที่หน้าหลัก) · Backend: `src/Hub.gs` · ทดสอบ: `scripts/hub-test.html`

## ปัญหาเดิม

| ปัญหา | ผลกระทบ |
|---|---|
| สมัครเข้าร่วมได้ทีละโครงการ และทุกคำขอต้องรอผู้ดูแลอนุมัติ | ขั้นตอนยาว คนเลิกกลางทาง |
| หน้าเว็บมีแต่บัญชีเจ้าหน้าที่ (รหัส 7 หลัก) | ประชาชน/บริษัทไม่รู้ว่าร่วมอะไรได้ ต้องหาฟอร์มเอง |
| โครงการรายหน่วยงาน (ตลับหมึก Paperless คัดแยก) ต้องให้ผู้ดูแลเพิ่มชื่อหน่วยงานเอง | หน่วยงานไม่มีช่องทางขอเข้าร่วม |
| ตัวเลขดูได้เฉพาะปีปฏิทิน | รายงานผู้บริหาร/งบประมาณใช้ปีงบประมาณ ต้องคำนวณเอง |

## แนวคิด: "เลือกว่าคุณคือใคร → ติ๊กหลายโครงการ → กดครั้งเดียว"

```
① เลือกกลุ่ม          ② ติ๊กโครงการ (หลายอัน)       ③ สมัครครั้งเดียว
🩺 เจ้าหน้าที่   ──▶  เห็นเฉพาะโครงการที่      ──▶  เจ้าหน้าที่: เข้าสู่ระบบครั้งแรก → สมัครทุกโครงการพร้อมกัน
🏢 หน่วยงาน          ผู้ดูแลเปิดให้กลุ่มนี้          หน่วยงาน: เจ้าหน้าที่ยื่นแทนหน่วยงาน → ผู้ดูแลอนุมัติ
🙋 ประชาชน            + ตัวเลขผลลัพธ์ของปีที่เลือก     ประชาชน/บริษัท: ลงทะเบียนครั้งเดียว ได้ "รหัสสมาชิก"
🏭 บริษัท/องค์กร
```

## ผู้ดูแลกำหนดได้ว่า "โครงการไหน ใครร่วมได้"

ปุ่ม **🛠️ ผู้ดูแล** (มุมขวาบนของ `join.html`) → เข้าสู่ระบบด้วยหน่วยงานผู้ดูแล + PIN เดิม → แท็บ **⚙️ ตั้งค่าโครงการ**

| ตั้งค่า | ความหมาย |
|---|---|
| 🩺 เจ้าหน้าที่ / 🏢 หน่วยงาน / 🙋 ประชาชน / 🏭 บริษัท | กลุ่มที่เห็นปุ่ม "เลือกโครงการนี้" |
| เปิดรับสมัคร | ปิด = ทุกคนยังดูผลได้ แต่สมัครไม่ได้ |
| อนุมัติอัตโนมัติ | สมัครแล้วเป็นสมาชิกทันที (คำขอของ **หน่วยงาน** รอผู้ดูแลเสมอ เพราะต้องตั้งค่าในโครงการ เช่น PIN ของ Paperless) |
| ลำดับ · ข้อความเชิญชวน · วิธีร่วม | แสดงบนการ์ดโครงการ |

ค่าเริ่มต้น (แก้ได้): ทอดไม่ทิ้ง = เจ้าหน้าที่ · Paperless / ตลับหมึก = หน่วยงาน · จากครัวสู่ท้องฟ้า = ดูผลอย่างเดียว · ปฏิทินเก่า / น้ำยา EM / ปุ๋ยหมัก = ทุกกลุ่ม · คัดแยก แบ่งปัน = เจ้าหน้าที่ + หน่วยงาน

ข้อมูลอยู่ในชีต `HubProjects` (แก้ในชีตตรงๆ ก็ได้)

## แต่ละกลุ่มทำงานอย่างไร

### 🩺 เจ้าหน้าที่ (หลายโครงการต่อคน)
- ใช้บัญชีเดิมของหน้าเว็บ (Portal.gs) — เข้าสู่ระบบครั้งเดียว เลือกได้หลายโครงการ (`hubJoinStaff`)
- บันทึกลง `PortalJoinRequests` เดิม → **กฎ "ต้องเป็นสมาชิกโครงการ" ของฟอร์มเดิมใช้ได้ทันที**
- **สมัครล่วงหน้าได้แม้บัญชียังรอยืนยัน** — เมื่อผู้ดูแลอนุมัติบัญชีแล้ว ใช้ฟอร์มได้เลย ไม่ต้องกลับมาสมัครซ้ำ

### 🏢 หน่วยงาน (หลายโครงการต่อหน่วยงาน)
- เจ้าหน้าที่ของหน่วยงานเข้าสู่ระบบ → เลือก/พิมพ์ชื่อหน่วยงาน → ติ๊กหลายโครงการ → ส่งคำขอ (`hubDeptJoin`)
- ผู้ดูแลอนุมัติ → ระบบ **เพิ่มชื่อหน่วยงานในรายชื่อของโครงการให้อัตโนมัติ** (Paperless / ตลับหมึก / คัดแยก ผ่าน `addProjectDepartment` เดิม; Paperless ใส่ PIN ของหน่วยงานตอนอนุมัติ)
- ตาราง "หน่วยงานไหน ร่วมโครงการอะไร" แสดงต่อสาธารณะ (ชื่อหน่วยงานเท่านั้น) — ค้นหาได้

### 🙋 ประชาชน / 🏭 บริษัท
- ลงทะเบียนครั้งเดียว **ไม่ต้องตั้งรหัสผ่าน**: ชื่อ (+ชื่อบริษัท) · เบอร์โทร · อีเมล (แนะนำ) · ติ๊กรับทราบ PDPA
- ได้ **รหัสสมาชิก** `P-XXXXXX` / `C-XXXXXX` (ส่งทางอีเมลด้วย) ใช้คู่กับเบอร์โทรเพื่อ ดูสถานะ / สมัครเพิ่ม / เลิกร่วม / ลบข้อมูลของตนเอง
- ลืมรหัส → กรอกเบอร์ + อีเมล → ระบบส่งรหัสไปที่อีเมลที่ลงทะเบียน (ตอบเหมือนกันทุกกรณี ไม่บอกว่ามีสมาชิกหรือไม่)
- โครงการที่มีฟอร์มสำหรับคนนอกอยู่แล้ว (ปฏิทิน ขอรับน้ำยา EM ขอรับปุ๋ยหมัก) มีปุ่ม "ร่วมกิจกรรม" ไปที่ฟอร์มนั้น

## ปี พ.ศ. และปีงบประมาณ

- `getPeriodSummary(key, year, basis)` — `basis = 'calendar'` (ม.ค.–ธ.ค., ค่าเดิม) หรือ `'fiscal'` (1 ต.ค. – 30 ก.ย.)
- ปีงบประมาณ 2570 = 1 ต.ค. 2569 – 30 ก.ย. 2570 (ต.ค.–ธ.ค. นับเป็นปีงบถัดไป) · รายเดือนเรียง ต.ค. → ก.ย.
- ใช้ได้ทั้ง **หน้า "ร่วมโครงการ"** (การ์ด + กราฟรายเดือน + ตารางรายปี) และ **การ์ด "สรุปรายเดือน • รายปี • สะสม" ในระบบหลัก** (ปุ่ม `ปี พ.ศ. | ปีงบประมาณ` + Excel/PDF ตามฐานที่เลือก)
- เรียกแบบเดิม (2 พารามิเตอร์) ได้ผลเหมือนเดิมทุกประการ — สไลด์ผู้บริหารและ API เดิมไม่เปลี่ยน

## API

| GET `?api=` | ข้อมูล (ไม่มีข้อมูลบุคคล) |
|---|---|
| `hubHome&basis=fiscal&year=2027` | โครงการ + ใครร่วมได้ + จำนวนสมาชิกแยกกลุ่ม + ตัวเลขหลักของปีที่เลือก |
| `hubProject&key=em&basis=fiscal&year=2027` | รายเดือน/รายปี/สะสมของโครงการเดียว |
| `hubDepartments` | หน่วยงาน × โครงการ |
| `hubAdminDepts` | รายชื่อหน่วยงานสำหรับหน้าเข้าสู่ระบบผู้ดูแล |

POST `{action:…}`: `hubJoinStaff` · `hubStaffStatus` · `hubDeptJoin` · `hubRegister` · `hubMemberStatus` · `hubMemberJoin` · `hubMemberLeave` · `hubMemberDelete` · `hubRecoverMember` · `hubAdmin` (`op`: login, inbox, catalog, saveCatalog, reviewAccount, reviewStaffJoin, reviewHubJoin, members)

## ความปลอดภัย / PDPA
- API สาธารณะคืนเฉพาะตัวเลขรวมและชื่อหน่วยงาน · หน้าเว็บแสดงชื่อ/เบอร์/รหัสแบบปกปิดบางส่วน
- ผู้ดูแลเห็นข้อมูลเต็มหลังตรวจ PIN (ผิด 5 ครั้งล็อก 10 นาที) และทุกการเปิดดู/อนุมัติถูกบันทึกใน `PortalAudit`
- รหัสสมาชิก + เบอร์ผิด 6 ครั้งล็อก 10 นาที · ลงทะเบียนเกิน 30 ครั้ง/10 นาทีถูกชะลอ · เบอร์ซ้ำไม่เปิดเผยรหัสเดิม
- PIN ผู้ดูแลส่งผ่าน POST เท่านั้น และไม่เก็บไว้ในเบราว์เซอร์
- ข้อจำกัด: รหัสสมาชิกภายนอกเป็น "รหัสลับ + เบอร์โทร" ไม่ใช่รหัสผ่าน — เหมาะกับข้อมูลระดับสถานะการร่วมโครงการ ไม่ควรใช้ปกป้องข้อมูลอ่อนไหวกว่านี้

## ติดตั้ง / อัปเดต
1. เพิ่มไฟล์ `Hub.gs` ใน Apps Script และอัปเดต `Code.gs`, `JS.html` (มีการแก้ `getPeriodSummary`, `doGet`, `doPost` และการ์ดสรุป)
2. Deploy → Manage deployments → แก้ไข → **New version** (ลิงก์ `/exec` เดิม)
3. เปิด `join.html` — ชีต `HubProjects` ถูกสร้างพร้อมค่าเริ่มต้น → ผู้ดูแลปรับในแท็บ "ตั้งค่าโครงการ"
4. ก่อน Deploy ทดสอบได้ที่ `join.html?demo=1` (ข้อมูลตัวอย่าง ไม่บันทึกจริง) — ถ้า backend ยังไม่มี Hub.gs หน้าเว็บจะเข้าโหมดตัวอย่างเองพร้อมแจ้งเตือน
