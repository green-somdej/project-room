⚙️ ยังไม่ได้เชื่อมต่อระบบ

หน้านี้จะแสดงระบบจริงเมื่อใส่ลิงก์ Web App ของ Apps Script ในไฟล์ docs/config.js

  1. ใน Apps Script ไปที่ Deploy → Manage deployments แล้วคัดลอก Web app URL (ลงท้ายด้วย /exec)
  2. เปิดไฟล์ docs/config.js บน GitHub แล้วกดปุ่มดินสอ ✏️
  3. วางลิงก์ใน APP_URL: '' เช่น APP_URL: 'https://script.google.com/macros/s/…/exec'
  4. กด Commit changes รอ 1–2 นาที แล้วรีเฟรชหน้านี้
แก้ไข config.js บน GitHub ดูหน้าแนะนำโครงการ
