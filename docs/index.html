สิทธิ์การเข้าถึงที่ปลอดภัยSafe access control

ตอบคำถามเรื่องโครงการ วิธีเข้าร่วม และสถิติ ถ้าตอบไม่ได้ส่งต่ออีเมลถึงเจ้าหน้าที่ — และปฏิเสธการขอ PIN เสมอAnswers about campaigns, how to join and stats; escalates to staff by email, and always refuses PIN requests.

รายงานผลกระทบImpact reporting

เปลี่ยนตัวเลขกิจกรรม
ให้เป็นต้นไม้และ CO₂Turn activity into trees and CO₂

ค่าแปลงทั้งหมดเป็นค่าประมาณทั่วไป และปรับแก้ได้ในชีต EnvironmentalSettings โดยไม่ต้องแก้โค้ด เพื่ออ้างอิงตามมาตรฐานที่โรงพยาบาลเลือกใช้All conversion factors are general estimates, editable in the EnvironmentalSettings sheet without touching code.

// ค่าเริ่มต้น (แก้ได้ในชีต / defaults, editable in sheet)
paper  : A4 8,333 sheets  = 1 tree
paper  : 0.0046 kg CO₂ / sheet
oil    : 2.5  kg CO₂ / liter reused
toner  : 2    kg CO₂ / kg recycled
tree   : absorbs 20 kg CO₂ / year

// → รวมเป็น "ต้นไม้เทียบเท่า"
treesEquivalent = totalCO2Avoided / 20

Deploy เป็น Web AppDeploy as Web App

เลือก Execute as Me, Who has access Anyone แล้วแชร์ลิงก์ /exec ให้บุคลากรExecute as Me, access Anyone, then share the /exec link with staff.

terminal
$ git clone https://github.com/kan200837-blip/hospital-eco-tracker.git
$ cd hospital-eco-tracker && npm install
$ npx clasp login
$ npx clasp create --type webapp --title "Hospital Eco Tracker" --rootDir src
$ npm run push    # อัปโหลดโค้ด / upload code
$ npm run deploy  # สร้าง Web App / create web app

FAQ

คำถามที่พบบ่อยFrequently asked questions

มีค่าใช้จ่ายไหม?Does it cost anything?

ไม่มีค่าเซิร์ฟเวอร์ ใช้โควตาฟรีของบัญชี Google (หรือ Google Workspace ขององค์กร) ซอร์สโค้ดเป็น MIT License ใช้และปรับแก้ได้อย่างอิสระNo hosting cost — it runs on your Google account's free quotas (or your Google Workspace). The code is MIT-licensed.

ข้อมูลผู้ป่วยหรือข้อมูลส่วนบุคคลอยู่ที่ไหน?Where is data stored? Is any patient data involved?

ระบบนี้ไม่เกี่ยวข้องกับข้อมูลผู้ป่วย เก็บเฉพาะข้อมูลกิจกรรมสิ่งแวดล้อม ข้อมูลทั้งหมดอยู่ใน Google Sheets ของคุณเอง ไม่ได้อยู่ในรีโปนี้ ควรตรวจสอบนโยบายข้อมูลส่วนบุคคล (PDPA) ของหน่วยงานก่อนเก็บชื่อ/เบอร์โทรผู้เข้าร่วมกิจกรรมThe system holds only environmental-activity data — no patient records. All data lives in your own Google Sheet, never in this repo. Review your organisation's data-protection policy before collecting names or phone numbers.

PIN เริ่มต้นคืออะไร และต้องทำอย่างไร?What is the default PIN?

ข้อมูลตัวอย่างใช้ PIN 123456 ซึ่งเป็นค่าสำหรับทดลองเท่านั้น ต้องเปลี่ยนก่อนเปิดใช้งานจริง ดูขั้นตอนใน SECURITY.mdSample setup uses PIN 123456 for trials only. Change it before going live — see SECURITY.md.

ปรับแต่งชื่อโรงพยาบาลหรือเพิ่มโครงการใหม่ได้ไหม?Can I rebrand it or add campaigns?

ได้ ชื่อระบบอยู่ใน Index.html และ doGet() ส่วนโครงการใหม่ทำตามโครงสร้างโมดูลเดิม (ชีต + ฟังก์ชัน + แท็บ + ธีมสี) อ่านแนวทางใน CONTRIBUTING.mdYes. Titles live in Index.html and doGet(); new campaigns follow the existing module pattern (sheets + functions + tab + color theme) — see CONTRIBUTING.md.

รองรับผู้ใช้พร้อมกันได้กี่คน?How many concurrent users?

เหมาะกับโรงพยาบาลหนึ่งแห่ง ระบบมีแคชและ LockService ลดการอ่าน/เขียนชนกัน แต่ยังอยู่ภายใต้โควตาของ Apps Script ที่ Google กำหนดDesigned for a single hospital. Caching and LockService reduce read/write collisions, but Apps Script quotas still apply.
